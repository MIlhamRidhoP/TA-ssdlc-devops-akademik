  • KritisSQL Injection pada pencarian mahasiswa› src/controllers/mahasiswa.controller.js:48 · CWE-89 · Sonar + Gemini 
    47const { nama } = req.query;
48const sql = `SELECT * FROM mahasiswa WHERE nama LIKE '%${nama}%'`;49const rows = await db.query(sql);
    Kenapa rentan

    Nilai nama dari query string disisipkan langsung ke string SQL, sehingga penyerang bisa menambah klausa sendiri.

    Rekomendasi

    Pakai parameterized query, misalnya db.query("… LIKE ?", [`%${nama}%`]), dan batasi panjang input.

    Rekomendasi AI
  • KritisSQL Injection pada parameter sorting admin› src/controllers/admin.controller.js:112 · CWE-89 · Gemini
    Kenapa rentan

    Nama kolom untuk ORDER BY diambil dari input tanpa whitelist. Parameterized query tidak melindungi nama kolom.

    Rekomendasi

    Cocokkan input dengan daftar kolom yang diizinkan sebelum disusun ke query.

    Rekomendasi AI
